# Terra versus Sol fixer trial — 2026-10-28

Recommendation: trial Terra for tightly scoped fixes, with Sol retained for
independent review and broader implementation. This small run supports the trial;
it does not establish equivalent quality on real project work.

The local Codex CLI (0.165.0, ChatGPT login) ran each model once on five seeded
regressions in `tools/session-usage.py`, at medium reasoning effort. Each attempt
started in a fresh temporary workspace with identical fixer instructions, mutated
source, and the existing 24-test suite. Model order alternated by case. The CLI
used its workspace-write sandbox, ignored user configuration, and ran without
session persistence. The host evaluated the resulting source in another fresh
workspace with the original tests. Baseline passed and every seed failed before
model attempts. No retries or human corrective work were supplied.

| Automatic agent exclusion | 12.116 | 18.268 | Both 24/24 |

Terra used 45.2% less total CLI elapsed time in this run and was faster in all five
pairs. Durations include CLI startup and model tool use, excluding host scoring.
Token counts are reported `turn.completed` usage, not billing figures. Cache
state was not controlled, and no subscription credit or monetary savings are inferred.

Both models restored the original source exactly in the first four cases. For
pause overlap, Sol reused the existing `union_seconds()` helper; Terra added an
inline interval merge before summing durations. Both pass the existing tests, but Terra duplicates
existing logic and changes the serialized `timing.pauses` records to sorted,
merged intervals. Baseline and Sol preserve individual clipped input records and
their order. A follow-up execution confirmed that overlapping inputs clipped to
00–04 and 02–06 become a single 00–06 record with Terra. Durations remain correct.
The existing suite does not assert that output field, so its pass result misses
this behavioral drift. Terra's fifth attempt warrants correction before adoption;
review found no behavioral drift in the other nine patches. Benchmark patches
were never applied to the working repository.
No attempts modified files outside their assigned source file.

Limitations: one attempt per model per seed; one Python module; explicit symptom
hints and visible tests; simple single-line seeded regressions; no hidden tests;
no broad implementation, architecture, or security evaluation. Prompt and runtime
overhead and cache behavior can affect comparisons. Repeat on matched real fixes,
including unseen edge cases and independent review, before treating this as a
reliable general quality or cost comparison.

Reproduce from the repository checkout:

```sh
python3 -B tools/benchmark-fixer.py --dry-run
python3 -B tools/benchmark-fixer.py --output /tmp/fixer-comparison-new
```

The output directory must be new and outside the checkout. Raw artifacts for this
run are at `/private/tmp/fixer-terra-sol-20261028`: summary JSON and Markdown,
per-attempt event logs, timing and usage records, final source and patches, and
host evaluator logs. Temporary artifacts may be cleaned by the operating system.
The run completed without infrastructure errors. The runner's later correction
classifies model-produced evaluator hangs as code failures; no timeouts occurred
in this run, so the correction does not change these results.
